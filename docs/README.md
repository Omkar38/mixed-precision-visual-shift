# Active documentation

Use this folder for documents that guide current work and are updated as the
project progresses.

## Start here

1. [`live_STATUS.md`](live_STATUS.md) — current milestone, completed work,
   blockers, and the next task.
2. [`PROJECT_PLAN.md`](PROJECT_PLAN.md) — milestone order, acceptance criteria,
   experimental controls, and data/output contracts.
3. [`DECISIONS.md`](DECISIONS.md) — accepted and proposed scientific choices.

`PROJECT_CONTEXT.md` and `AGENTS.md` remain at the repository root because they
are entry-point instructions.

Historical findings, completed setup guides, proposal snapshots, and earlier
progress reports are in [`../passive_docs/`](../passive_docs/README.md). They
provide evidence and context but do not override `live_STATUS.md`,
`DECISIONS.md`, or `PROJECT_PLAN.md`.
